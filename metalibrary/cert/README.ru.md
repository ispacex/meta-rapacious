# cert/ — проверяемое доказательство расхождения хищного правила с Тодой

**Утверждение.** Если применить хищное правило (стрелки $d_r\colon(n,s,c)\to(n-1,s+r,c+1)$,
$r\ge2$, максимальный ранг на каждой странице) к настоящему листу $E^2$ метабиблиотеки, то над
$\pi_n(S^2)$ остаётся

| $n$ | правило (оба порядка заполнения) | Тода 2003 |
|---|---|---|
| 49 | 2 | 1 |
| 50 | 3 | 1 |
| 51 | 1 | 0 |
| 59 | 2 | 1 |
| 60 | 1 | 0 |

Значения Тоды не доказываются, а цитируются (`../toda2003.py`). Доказывается только левый столбец,
и так, чтобы проверка не зависела от нашего кода, который считал $E^2$ (`lambda3.py`, `rust/`).

## Как устроено

1. **Локальность** (`plan.py`). Правило проводит стрелки только между ненулевыми клетками $E^2$, поэтому
   оно идёт отдельно на каждой компоненте связности графа возможных стрелок. Для столбцов $N$
   достаточно знать точные размерности клеток компонент, задевающих эти столбцы, и то, что все
   соседние клетки (на одну возможную стрелку) и все прочие клетки столбцов нулевые.
   π₄₉–π₅₁: 89 клеток (20 ненулевых), 100 блоков дифференциала, n = 48…54.
   π₅₉–π₆₀: 86 клеток (17 ненулевых), 111 блоков, n = 58…62; самый большой блок 308 910 × 269 346.
2. **Сертификаты** (`../rust/src/bin/cert.rs`; программа не доверенная, только пишет файлы).
   - *Ранг блока* $d\colon(n,s,c)\to(n-1,s+1,c)$ не меньше $r$: $r$ строк `y t w:k …` —
     вектор $y=\sum k\,w$ из слов-источников и слово-цель $t$. Каждое $d(y_i)$ содержит своё $t_i$
     и не содержит $t_j$ при $j>i$; матрица коэффициентов треугольная с ненулевой диагональью,
     значит $d(y_i)$ независимы. Проверка не требует исключения Гаусса, только вычисления $d$.
     В среднем в $y$ полтора слова.
   - *Ненулевая клетка* размерности $h$: $h$ циклов $z$ ($dz=0$) и $h$ коциклов $\varphi$
     ($\varphi\circ d=0$ на клетке выше) с обратимой матрицей $\varphi_j(z_i)$; отсюда $\dim\ge h$.
   - Из оценок рангов снизу: $`\dim\le\#\text{слов}-\mathrm{rk}_\text{out}-\mathrm{rk}_\text{in}`$.
     Вместе — точная размерность.
3. **Проверялка** `check.py` написана заново по [arXiv:1506.00952](https://arxiv.org/abs/1506.00952), §2 (соотношения, $\partial$,
   допустимость, перечисление слов) и не импортирует ничего из `metalibrary/`. Нормальная форма
   в ней — переписывание самой левой недопустимой пары (в Rust — рекурсия по последней букве).
   Она проверяет сертификаты, точность всех заявленных размерностей, замкнутость набора клеток
   относительно стрелок правила, полноту столбцов и сама прогоняет правило.
   `selftest.py` портит сертификат четырьмя способами — каждая порча отвергается.
4. **Lean 4** (`lean/`): третья реализация алгебры и тех же проверок; теорема
   `rule_survivors : checkAll … = some […]` доказывается `native_decide`
   (доверяем компилятору Lean, это отмечено).

## Воспроизвести

Локально, на малом наборе ($\pi_{22}$, $\pi_{23}$, секунды; нужны `cargo` и `python3`):

```bash
cd metalibrary
(cd rust && cargo build --release --bin cert)
rust/target/release/cert cert/blocks_22_23.txt cert/cells_22_23.txt /tmp/cert_22_23 1
python3 cert/check.py cert/cells_22_23.txt /tmp/cert_22_23 22 23
python3 cert/selftest.py cert/cells_22_23.txt /tmp/cert_22_23 22 23
```

Опубликованные сертификаты — тем же `check.py`, без генератора:

```bash
curl -LO https://github.com/ispacex/metalibrary/releases/download/certificates-2026-10-15/cert_49_50_51.tar.gz
tar -xzf cert_49_50_51.tar.gz
python3 cert/check.py cert/cells_49_50_51.txt cert_49_50_51 49 50 51
```

Полные прогоны — на удалённой машине (`../../remote/`, из корня репозитория):

```bash
python3 metalibrary/cert/plan.py 49 50 51     # cells_49_50_51.txt, blocks_49_50_51.txt
remote/mr-remote.sh submit --name cert -- 'cd metalibrary && cert/run.sh 49 50 51'
remote/mr-remote.sh submit --name lean -- 'cd metalibrary/cert/lean && ./run.sh 49_50_51 49:2:2 50:3:3 51:1:1'
```

`lean/run.sh` берёт архив из каталога `$CERT_ARCHIVE` или скачивает его из релиза и сверяет с `SHA256SUMS`, `gen_stage.py` пишет
`MetalibCert/Stage_<TAG>.lean` с теоремой `rule_survivors`, `lake build` её проверяет.
Lean-проект без Mathlib: только ядро Lean и `Std`.

## Чего здесь нет

- Значения Тоды не проверяются.
- Что лист $E^2$ этого комплекса — $E^2$ спектральной последовательности из статьи, и что лямбда-
  алгебра задана формулами §2 верно, — математика статьи. Проверялки проверяют $d^2=0$ на всех
  словах малых клеток как тест соглашений (в частности, $N(k)$ с потолком).
- Само правило — наше прочтение лекции (`../rapacious.py`).
