# metalibrary/ — лист E² цветной метабиблиотеки и «хищная спектралка»

Михайлов в лекции 02.09.2016 утверждает:
3-кручение $\pi_n(S^2)$ получается из листа $E^2$ «цветной метабиблиотеки», если
спектральная последовательность съедает себя как можно быстрее и ограничена только
цветом. Здесь $E^2$ посчитан с нуля и правило прогнано.

Раздел «Результаты» ниже — состояние на $\pi_{64}$, по прямому перебору. Текущие результаты —
цвета до $\pi_{150}$ по $Q$-весу, правило окончательно до $\pi_{149}$ — на сайте
https://ispacex.github.io/metalibrary/ru/, который `../site/build_site.py` собирает из `data/`.

## Что посчитано

1. **Mod-3 лямбда-алгебра** (`lambda3.py`): соотношения, дифференциал и допустимость
   по Иванову–Михайлову–Ву ([arXiv:1506.00952](https://arxiv.org/abs/1506.00952), §2), переписывание в допустимый базис.
   В статье стоит $N(k)=k-[\tfrac{k+1}{p}]$; скобки здесь — потолок: при «поле»
   соотношение для $k=1$ содержало бы собственную левую часть.
2. **Проверки** (`check_lambda.py`): $\partial^2=0$ и $\partial\Lambda(1)\subseteq\Lambda(1)$
   на всех 2,2 млн словах до стема 43; $H(\Lambda(1))$ совпадает с нестабильным Ext сферы $S^3$
   при $p=3$, посчитанным независимой программой sseq/ext (`resolve_unstable`, модуль
   `S_3[3]`, https://github.com/JoeyBF/sseq), в каждой клетке (стем, $s$).
3. **Метабиблиотека** в определении Михайлова: допустимые слова в $\lambda_i,\mu_i$
   ($i\ge1$), начинаются с $\lambda_1$ или $\mu_1$, кончаются на $\lambda$. Это ровно слова
   $\Lambda(1)$ без $\mu_0$, кончающиеся на $\lambda$. Они образуют подкомплекс
   $\Lambda(1)/\Lambda(1)\mu_0$ — проверяется на каждом слове. Гомологии по $(n,s,\text{цвет})$:
   `metalib.py` (Python, до $\pi_{56}$) и `rust/` (то же на Rust, в 20+ раз быстрее,
   побайтно совпадает с Python до $\pi_{56}$).
4. **Сверка**: при $n>3$ гомологии метабиблиотеки равны $H(\Lambda(1))$ поклеточно
   по $(n,s,\text{цвет})$ (проверено до $\pi_{46}$) и равны Ext из sseq по $(n,s)$
   (`compare_sseq.py`, до последнего посчитанного $n$). То есть выбрасывание $\mu_0$
   и слов на $\mu$ убирает только башню над $\pi_3=\mathbb Z$.
5. **Хищное правило** (`rapacious.py`): $d_r\colon (n,s,c)\to(n-1,s+r,c\pm1)$, на каждой странице
   берётся максимальный ранг, страницы по порядку.

## Результаты (данные до $\pi_{64}$)

Перебор метабиблиотеки на Rust досчитан до $n=64$ (141 с, 1,9 ГБ). Прогон до $n=72$
остановлен на середине; дальше считали на удалённой машине (`../remote/`).

- **Метабиблиотека = $E^2$ для $S^3$.** $E^2$ метабиблиотеки совпадает с Ext из sseq
  во всех 188 классах при $4\le n\le64$.
- **Цвета сэндвичей и элементов Тоды** идут 3 4 4 5 5 6 …, как сказано в лекции.
- **Хищное правило, цвет $+1$** (`data/rapacious.json`), сравнение с таблицей Тоды 2003
  (`toda2003.py`):
  - совпадает при всех $n\le48$, то есть в стемах $k<46$, которые Тода определил в 1967 году.
    Развилки $\pi_{41},\pi_{43}$ решаются в пользу заполнения «low»;
  - $\pi_{44}=0$ и $\pi_{48}=0$;
  - дальше правило оставляет лишние классы: в $\pi_{49},\pi_{50},\pi_{51},\pi_{59},\pi_{60},\pi_{63}$
    (на 1–2 больше, чем у Тоды). В $\pi_{49}\text{–}\pi_{60}$ их снимают $d_5$, сохраняющие цвет:
    $\pi_{50}(5,0)\to\pi_{49}(10,0)$, $\pi_{51}(5,1)\to\pi_{50}(10,1)$, $\pi_{60}(7,0)\to\pi_{59}(12,0)$.
    Если разрешить все такие $d_5$, ломаются $\pi_{57},\pi_{58}$;
  - цвет $-1$ не даёт ни одного дифференциала: $\pi_{44}$ остаётся равным 4.

## Цвет без перебора

`colour_solver.py` восстанавливает цвета классов $E^2$ по Ext из sseq
(`data/sseq_S3_p3_150.csv`, $n\le150$) и трём ограничениям:
- $c \equiv m-3 \pmod 4$ на диагонали $m=n+s$;
- $0 \le c \le s-1$;
- эйлерова характеристика $\chi(m,c)$, которая считается по числу слов, без линейной алгебры.

Для каждой клетки целочисленное ЛП даёт наименьшее и наибольшее число классов каждого цвета.

Прогон на удалённой машине (`../remote/`, 9 с):
- при $n\le64$ все ответы согласуются с перебором, 99 клеток определены точно;
- до $n=84$ однозначно определены 146 классов из 394, в том числе 47 клеток при $64<n\le84$;
- для остальных 248 классов нужен перебор.

Результат лежит в `data/e2_colours.csv`: `status = determined` или `range lo..hi`.

## Цвет по модулю 4

Стем слова равен $`4\sum(\text{индексы})-\#\lambda`$, поэтому
$\text{цвет}\equiv\text{стем}+s \pmod 4$. Отсюда стрелка «цвет $+1$» возможна только
при $r\equiv2\pmod4$, то есть для $d_2, d_6, d_{10},\dots$. Сам цвет — отдельная градуировка:
число бокштейнов, $Q$-степень в Ext. Ext из sseq её не видит, поэтому
метабиблиотеку пришлось считать самим.

## Файлы

- `lambda3.py`, `check_lambda.py` — алгебра и её проверки.
- `metalib.py` — гомологии метабиблиотеки или $\Lambda(1)$ по цвету (Python).
- `rust/` — `cargo build --release && target/release/metalib NMAX [THREADS] > data/e2_metalib.csv`.
- `compare_sseq.py` — сверка с sseq/ext.
- `rapacious.py` — хищное правило, варианты и проверки; `--list` печатает дифференциалы.
- `plot_e2.py` — картинка `out/7_e2_rapacious_{ru,en}.png`.
- `data/e2_metalib.csv` — $`n,s,\text{цвет},\#\text{слов},\mathrm{rank}\,\partial,\dim E^2`$;
  `data/e2_lambda1.csv` — то же для $\Lambda(1)$ до $\pi_{46}$;
  `data/sseq_S3_p3.csv` — Ext из sseq до $n=86$; `data/rapacious.json` — итог правила.
- `colour_solver.py`, `colours_to_e2.py` — цвета без перебора (выше); `data/e2_colours.csv`, `data/e2_full.csv`.
- `open_blocks.py`, `needed_blocks.py`, `select_blocks.py`, `split_blocks.py`, `pick_blocks.py`,
  `merge_ranks.py`, `compare_ranks.py` — какие блоки дифференциала досчитать перебором
  (`rust/src/bin/lowmem.rs`), и точные размерности из их рангов: `data/e2_known.csv`, `data/*blocks*.txt`.
- `qgrade_to_e2.py`, `check_qgrade.py` — цвет как $Q$-вес Ext из форка sseq
  (https://github.com/ispacex/sseq, ветка `math-54-qgrade`, пример `qgrade_dims`) и его сверка с
  лямбда-алгеброй: `data/sseq_qgrade_S3_p3_150.csv`, `data/e2_qgrade.csv` ($E^2$ с цветами до $\pi_{150}$).
- `toda2003.py` — таблица Тоды 2003 года (3-примарные $\pi_{3+k}(S^3)$, $k\le79$), прочитанная со скана.
- `data/s2_3torsion.csv` — 3-кручение $\pi_n(S^2)$ по таблице Тоды 1962 года ($n\le22$, столбец
  `toda_rank`), элементы Тоды и сэндвичи (Иванов–Михайлов–Ву) и утверждения лекции; сверено по двум
  перепечаткам таблицы Тоды (Равенель, табл. A3.4, и таблица PKU).
- `cert/` — проверяемые сертификаты расхождения правила с Тодой в $\pi_{49}\text{–}\pi_{51}$, $\pi_{59}$, $\pi_{60}$
  ([`cert/README.ru.md`](cert/README.ru.md)).

## Как воспроизвести sseq

```bash
git clone https://github.com/JoeyBF/sseq && cd sseq/ext
# пример unstable_dims.rs: resolve_unstable, печатающий n,s,dim (лежит в metalibrary/sseq_unstable_dims.rs)
cp .../metalibrary/sseq_unstable_dims.rs examples/unstable_dims.rs
cargo build --release --example unstable_dims
printf 'S_3[3]\n\n86\n40\n' | target/release/examples/unstable_dims > sseq_S3_p3.csv
```
